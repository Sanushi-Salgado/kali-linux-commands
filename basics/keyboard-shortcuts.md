# ⌨ Keyboard Shortcuts 🐉

---

```bash
Ctrl + Alt + T 													# 🖥️ Open new terminal 		
			
Shift + Insert 													# 📋 Paste         
 					
Ctrl + A      													# 🔘 Select all     

Ctrl + C														# 🛑 Stop terminal process

Ctrl + Shift + F												# 🔍 Search for a word / phrase within the terminal output
```
