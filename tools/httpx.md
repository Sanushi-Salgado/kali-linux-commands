# 💻 Httpx Commands 🐉

---

## ✅ Verification 

```bash
httpx -version                                           # 🛠️ Get the installed httpx version

<path to the installed httpx executable> -version        # 🛠️ Get the installed httpx version of the given binary

which httpx                                              # 📍 Get the path to the installed httpx executable

httpx -h                                                 # ❓ Get help / usage information for httpx
```
