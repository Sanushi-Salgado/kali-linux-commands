# 💻 Wappalyzer Commands 🐉

---

## ✅ Verification 

```bash
which wappalyzer  																# 📍 Get the path to the installed Wappalyzer executable

wappalyzer -h																	# ❓ Get help / usage information for Wappalyzer
```

---

## 🛠️ Usage

```bash
wappalyzer                     													# 🚀 Launch Wappalyzer 

PUPPETEER_EXECUTABLE_PATH=<chromium path> wappalyzer <URL> --pretty             # 🌐 Get information related to a URL in JSON format
```
