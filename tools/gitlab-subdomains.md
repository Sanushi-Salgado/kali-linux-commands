# 💻 Gitlab-Subdomains Commands 🐉

---

## ✅ Verification 

```bash
which gitlab-subdomains                                       # 📍 Show the path to the installed Gitlab-Subdomains executable

gitlab-subdomains -h                                          # ❓ Display help / usage information for Gitlab-Subdomains
```

---

## 🛠️ Usage

```bash
gitlab-subdomains -d <domain> -t <Gitlab token>		  	      # 🔍 Get subdomains of a given domain

gitlab-subdomains -d <domain>                                 # 🔍 Get subdomains of a given domain (via GITLAB_TOKEN environment variable)
```
