# 💻 Subdominator Commands 🐉

---

## ✅ Verification 

```bash
which subdominator                                # 📍 Get the path to the installed Subdominator executable

subdominator -h                                   # ❓ Get help / usage information for Subdominator 
```

---

## 🛠️ Usage

```bash
subdominator -d <domain>                          # 🌐 Get subdomains related to a domain
```
