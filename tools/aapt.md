# 💻 Aapt Commands 🐉

---

## 🔄 Installation

```bash
sudo apt install -y aapt								   #  📦 Install Aapt via apt
```

---

## ✅ Verification 

```bash
which aapt	                                                # 📍 Show the path to the installed Aapt executable

aapt version												# 🛠️ Get the installed Aapt version
```

---

## 🛠️ Usage

```bash
aapt 	                     								# 🚀 Launch Aapt 
```
