# 💻 WhatWeb Commands 🐉

---

## ✅ Verification 

```bash
whatweb --version															# 🛠️ Get the installed WhatWeb version

which whatweb  																# 📍 Get the path to the installed WhatWeb executable

whatweb --help																# ❓ Get help / usage information for WhatWeb
```

---

## 🛠️ Usage

```bash
whatweb                     												# 🚀 Launch WhatWeb 

whatweb <domain URL> -a 3 --log-json=-                                  	# 🌐 Get information related to a domain in JSON format
```
