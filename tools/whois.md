# 💻 Whois Commands 🐉

---

## ✅ Verification 

```bash
whois --version	 									# 🛠️ Get the installed Whois version

which whois  										# 📍 Get the path to the installed Whois executable

whois --help										# ❓ Get help / usage information for Whois
```

---

## 🛠️ Usage

```bash
whois                     							# 🚀 Launch Whois 

whois <domain>                                  	# 🌐 Get information related to a domain
```
