# 💻 CDNCheck Commands 🐉

---

## 🔄 Installation

```bash
go install -v github.com/projectdiscovery/cdncheck/cmd/cdncheck@latest			#  📦 Install cdncheck (latest version) using Go
```

---

## ✅ Verification 

```bash
which cdncheck                                                                  # 📍 Get the path to the installed cdncheck executable

cdncheck -h                                                                     # ❓ Get help / usage information for cdncheck
```

---

## 🛠️ Usage

```bash
cdncheck -i <IP address>														# 🌐 Get information related to an IP address
```
