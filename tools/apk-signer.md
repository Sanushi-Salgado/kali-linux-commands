# 💻 APKSigner Commands 🐉

---

## 🔄 Installation

```bash
sudo apt install apksigner                                        #  📦 Install APKSigner via apt
```

---

## ✅ Verification 

```bash
which apksigner                                                  # 📍 Show the path to the installed APKSigner executable

apksigner version                                                # 🛠️ Get the installed APKSigner version

apksigner help                                                   # ❓ Get help / usage information for APKSigner
```
