# 💻 Gplaydl Commands 🐉

---

## 🔄 Installation

```bash
sudo python3 -m pip install --break-system-packages gplaydl      #  📦 Install Gplaydl via pip (isolated environment)
```

---

## ✅ Verification 

```bash
which gplaydl                                                    # 📍 Show the path to the installed Gplaydl executable

gplaydl -V                                                       # 🛠️ Get the installed Gplaydl version

gplaydl --help                                                   # ❓ Get help / usage information for Gplaydl
```
