# 💻 JADX Commands 🐉

---

## 🔄 Installation

```bash
sudo apt install -y jadx								   #  📦 Install JADX via apt
```

---

## ✅ Verification 

```bash
which jadx                                                 # 📍 Show the path to the installed JADX executable

jadx --version                                             # 🛠️ Get the installed JADX version

jadx-gui --version										   # 🛠️ Get the installed JADX-GUI version

jadx --help                                                # ❓ Get help / usage information for JADX
```
