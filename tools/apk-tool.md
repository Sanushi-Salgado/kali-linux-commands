# 💻 APKTool Commands 🐉

---

## 🔄 Installation

```bash
sudo apt install -y apktool								   #  📦 Install APKTool via apt
```

---

## ✅ Verification 

```bash
which apktool                                               # 📍 Show the path to the installed APKTool executable

apktool --version                                           # 🛠️ Get the installed APKTool version
```

---

## 🛠️ Usage

```bash
apktool                     								# 🚀 Launch APKTool 
```
